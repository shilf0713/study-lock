Core Features

StudyLock만의 강력한 핵심 기능

🛡️
로컬 VPN 트래픽 필터링
외부 원격 서버를 거치지 않고 오직 기기 내부에서 카카오톡을 제외한 유튜브, SNS, 게임, 포털 웹서핑 접속을 철저히 차단합니다.
🔗
6자리 초간편 페어링
복잡한 회원가입이나 계정 생성 없이, 학생 폰의 6자리 코드만 부모님 폰에 입력하면 1초 만에 실시간 원격 연결이 완료됩니다.
🛑
우회 차단 (강제종료 방어)
자녀가 설정창에 진입하여 앱을 강제 종료하거나 접근성을 끄는 시도를 실시간으로 감지하고 안전하게 원천 차단합니다.
🗑️
임의 앱 삭제(제거) 방지
기기 관리자(Device Admin) 보안 권한을 통해 부모님 비밀번호 없이 자녀가 앱을 임의로 삭제할 수 없도록 보호합니다.
🔑
원격 PIN 변경 & 분실 복구
자녀 폰의 잠금 해제 비밀번호는 부모님 폰에서 언제든 원격으로 변경할 수 있으며, 비밀번호를 잊어도 보안 질문으로 손쉽게 복구합니다.
🌐
다국어 지원 (한국어 & English)
국내외 어디서나 편리하게 이용할 수 있도록 한국어 및 영어를 기본 탑재하여 버튼 하나로 전환할 수 있습니다.
How To Use

간편한 6단계 이용 방법

1

양쪽 스마트폰에 앱 설치

동일한 StudyLock 앱을 부모님 스마트폰과 자녀 스마트폰에 모두 설치합니다.

2

기기별 역할 선택

부모님 폰은 [부모님용 모드], 자녀 폰은 [학생용 모드]를 선택합니다.

3

6자리 코드로 페어링(연결)

자녀 폰 화면에 표시된 6자리 번호를 부모님 폰에 입력하고 [연결] 버튼을 누릅니다.

4

🛡️ [필수] 학생 폰 보안 설정 (삭제 & 강제종료 방지 ON)

학생 폰 상단의 '[학생] 삭제 방지' 및 '[학생] 강제종료 방지' 버튼을 탭하여 권한을 켭니다.

5

원격 공부 모드(VPN) 작동

부모님 폰에서 스위치를 켜면 자녀 폰의 카카오톡 외 인터넷 연결이 즉시 차단됩니다.

6

비밀번호 관리 & 원격 변경

자녀 폰 비밀번호는 부모님 폰에서 원격으로 언제든 손쉽게 바꿀 수 있습니다.

🔒 사용자 개인정보는 완벽하게 보호됩니다

StudyLock은 회원가입이나 개인정보를 수집하지 않으며, 모든 인터넷 트래픽 차단은 오직 기기 내부(Local Loopback)에서만 수행됩니다. 외부 서버로 인터넷 사용 기록이나 패킷을 일절 전송하지 않습니다.
